# ReturnProof — Return file desk

Direction: consumer utility with the structure of an organized paper file. Comfortable density, a flat source column and a single paper-like result sheet. Real input and decision content lead the page. No generated imagery, public-product claims or invented metrics.

Palette: ink `#262721`, muted `#68685f`, desk `#f6f5f0`, file paper `#fffefa`, rail `#efeee8`, line `#d8d7cf`, burnt orange `#c6441c`, review tint `#f9ebe3`. Orange marks actions and unresolved attention; confirmation uses clear words and strong ink rather than an additional green palette.

Typography: Segoe UI/Arial chosen for familiar, legible consumer controls; Cascadia Code/Consolas for source references and arithmetic. No italic serif headline, oversized marketing promise or decorative letter-spaced eyebrow. Core controls use 13–14px type on desktop with 46px targets; mobile body/help stays readable at 12–14px. A compact 28–30px workspace title leaves the largest type for the actual deadline.

Layout: 184px file rail; asymmetric source/result split on wide screens; one reading column below 1000px; compact file strip on phones. No symmetric card pair or stack of nested rounded cards. One real result sheet, structural rules and source-document labels connect the appearance to the task.

Motion: short 250ms arrival with `cubic-bezier(.22,1,.36,1)`, small arrow hover movement. Reduced-motion preferences disable animation/transitions. Focus rings are explicit and orange. No decorative glow, hero gradient, glass or animated metrics.

Product craft: unsaved-change warning for New/example/open and page unload; visible saved/draft state; unchanged-source recheck preserves interpretation/checklist; source edits suppress the previous date; deletion includes a visible cancel path. All confirmations are self-reported consumer interpretations, never merchant approval.

This is an agent-selected design implementation responding to the user's explicit October 24 redesign request. It does not claim learner design approval or hands-on feedback.

Second October 24 revision: compact 60px header, 184px white file rail, restrained title, source action within the desktop first viewport and sticky Documents / Return file navigation on phones. Removed the empty-file catchphrase/icon, oversized empty count, redundant workflow numbers and rail slogan. An incomplete source document can be saved as a draft without analysis; opening it preserves draft status. The neutral top Save draft / Save changes action is separate from the orange Check return window action.

Evidence interaction refinement: competing rules use flat ruled rows with exact policy wording, date basis and two explicit date alternatives when counting is unknown. No decorative card grid or confidence score. Original-source actions use labelled keyboard-accessible buttons. Phone comparison headings clear the sticky navigation.
