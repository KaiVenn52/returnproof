# Third-party material

The six development curriculum skills under `.agents/skills/` come from [challengepost/learn-ai-basics](https://github.com/challengepost/learn-ai-basics), inspected at commit `a0f065781873e8a7ed9a9a705a8dafa6a0810439`. Their upstream MIT license is retained in `.agents/skills/LICENSE`. `skills-lock.json` records the installed content hashes. These are planning/build instructions, not application runtime code.

The application uses native browser APIs and Node built-ins, with no bundled third-party runtime library, external font, stock image or model. QA uses an existing Playwright installation and installed Edge; neither is distributed as application code. All included receipt/policy examples are fictional and labelled. No other existing project code was reused.
